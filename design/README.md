언어치료학 대학원생이 해부생리, 언어발달, 의사소통장애개론을 공부하는 iPad·iPhone 앱의 디자인 시스템입니다. 수업 사이 10분, 시험 전날 밤처럼 짧고 집중된 시간에 쓰는 도구입니다. 화면은 조용하고 정확해야 하며, 학생이 내용에만 집중하도록 물러서 있어야 합니다.

## 누구를 위한 앱인가

- 언어치료학 석사 과정 학생. 임상 실습과 수업을 병행해 시간이 부족합니다.
- 전공 용어(후두, 피열연골, 음운 변동, 브로카 실어증)에 익숙하며, 정확한 표현을 기대합니다.
- 주로 iPhone으로 퀴즈를 풀고, iPad로 학습자료를 읽고 모의고사를 봅니다.

## 디자인 원칙

1. **내용이 먼저입니다.** 장식보다 텍스트와 그림이 잘 읽히는 것이 우선입니다. 한 화면에 하나의 목적만 둡니다.
2. **차분하고 믿을 수 있게.** 따뜻한 오프화이트 바탕, 깊은 잉크색 글자, 강조색 하나. 화려한 그라데이션과 과장된 축하 표현을 쓰지 않습니다.
3. **과목은 색으로 알아봅니다.** 세 과목은 각자 정체성 색을 갖고, 그 색은 위치와 진도를 알려 주는 데만 씁니다.
4. **피드백은 즉시, 그리고 색 이외의 수단으로.** 정답·오답은 색, 아이콘, 라벨 세 가지로 동시에 알립니다.

## 콘텐츠 기본

### UI 문구의 어조

- 정중한 해요체를 씁니다. “시작할까요?”, “다시 풀어 보세요.”
- 문장은 짧게 씁니다. 버튼은 동사로 끝나는 2~6자: “시작하기”, “제출”, “오답 복습”.
- 느낌표와 이모지를 쓰지 않습니다. 칭찬은 사실로 전합니다: “지난번보다 8점 올랐어요.”
- 학생을 탓하지 않습니다. “틀렸습니다” 대신 “오답이에요. 해설을 확인해 보세요.”

### 퀴즈 문항과 피드백

- 문항은 하나의 개념만 묻습니다. 부정형(“아닌 것은?”)은 꼭 필요할 때만 쓰고 **아닌**을 굵게 표시합니다.
- 선택지는 4개, 길이와 문법 형태를 맞춥니다. “모두 옳다”는 쓰지 않습니다.
- 피드백은 결과 라벨 → 정답 → 한두 문장 해설 순서입니다. 예: “오답이에요. 정답은 ③ 윤상갑상근입니다. 성대를 길게 늘여 음높이를 올립니다.”
- 자세한 규칙은 「콘텐츠 작성」 섹션을 따릅니다.

### 한국어 타이포그래피 규칙

- 모든 텍스트에 `word-break: keep-all`을 적용해 어절 단위로 줄을 바꿉니다.
- 양쪽 정렬을 쓰지 않습니다. 본문은 왼쪽 정렬, 숫자 표는 오른쪽 정렬입니다.
- 숫자는 아라비아 숫자로 씁니다: “3장”, “12문항”, “8분”. 시간은 `24:37`, 점수는 `84점`.
- 영문 전공어는 처음 한 번만 괄호로 병기합니다: 성대(vocal folds).
- 문장 부호는 한국어 기준입니다. 가운뎃점(·)으로 메타 정보를 나눕니다: “12문항 · 15분”.

## 시각 기초

### 색

색 토큰은 라이트(기본)와 다크 두 테마를 갖습니다. 모든 텍스트 토큰은 자신이 놓이는 바탕 위에서 4.5:1 이상이며, 대비 값은 각 토큰의 설명에 적혀 있습니다.

- **바탕**: 화면은 `surface-page`, 카드와 목록은 `surface-card`, 시트와 고정 바는 `surface-elevated`, iPad 사이드바는 `surface-sidebar`.
- **글자**: 본문은 `ink-primary`, 보조 설명은 `ink-secondary`, 캡션은 `ink-tertiary`. 이보다 흐린 글자를 만들지 않습니다. `ink-primary`로 채운 면 위에서는 `ink-inverse`.
- **선**: 장식용 구분선은 `border-subtle`. 선택지·입력처럼 경계가 의미인 선은 `border-strong`(3:1 이상).
- **강조색**: `accent`(잉크 네이비) 하나뿐입니다. 주 버튼, 선택 상태, 활성 탭에만 씁니다. 주 버튼 라벨은 흰색이 아니라 `on-accent`입니다. 링크와 강조 텍스트는 `accent-ink`, 넓은 선택 바탕은 `accent-soft`.
- **과목색**: 언어기관해부생리 `subject-anatomy`(짙은 청록), 언어발달 `subject-development`(호박빛 갈색), 의사소통장애개론 `subject-disorders`(자두색). 세 색은 색상뿐 아니라 밝기도 다릅니다.
  - 과목색은 과목 카드 상단 띠, 탭 인디케이터, 진도 막대·링에만 씁니다. 본문 텍스트에는 절대 쓰지 않습니다.
  - 과목 이름이나 챕터 번호처럼 짧은 텍스트에는 `subject-*-ink`, 배지와 아이콘 타일 바탕에는 `subject-*-soft`.
- **피드백 색**: 정답 `correct`, 오답 `incorrect`, 주의 `warning`. 텍스트는 `*-ink`, 바탕은 `*-soft`.
  - 색만으로 구분하지 않습니다. 정답은 체크 아이콘과 “정답” 라벨, 오답은 X 아이콘과 “오답” 라벨, 주의는 시계·느낌표 아이콘과 문구를 반드시 함께 둡니다.
- **포커스**: 키보드·스위치 제어 포커스는 `focus-ring` 2px 실선과 2px 간격입니다. 모든 바탕에서 3:1 이상입니다.

### 타이포그래피

글꼴은 Google Fonts에서 제공하는 IBM Plex Sans KR(`--font-sans`)과 IBM Plex Mono(`--font-mono`)입니다. 앱에서는 동일 글꼴을 번들하거나 system-ui로 대체합니다.

| 스타일 | 크기/행간 | 쓰임 |
|---|---|---|
| `display` | 34/41 · 700 | 홈 인사말, 결과 제목. 화면당 하나 |
| `title` | 28/34 · 700 | 화면 큰 제목 |
| `heading` | 22/28 · 600 | 섹션 제목, iPad 카드 제목 |
| `subheading` | 17/22 · 600 | 목록 행 제목, 퀴즈 문항 |
| `body` | 17/24 · 400 | 본문, 선택지, 해설 |
| `callout` | 15/20 · 400 | 보조 설명, 세그먼트 라벨 |
| `caption` | 13/18 · 400 | 메타 정보, 탭 바 라벨 |
| `timer` | 20/24 · mono 500 | 남은 시간 |
| `score` | 56/60 · mono 600 | 결과 점수 |
| `figure` | 15/20 · mono 500 | 문항 번호, 퍼센트 |

- 시간과 점수는 반드시 mono 스타일(`timer`, `score`, `figure`)로 표시해 자릿수가 흔들리지 않게 합니다.
- 굵기는 400, 600, 700만 씁니다. 기울임꼴은 쓰지 않습니다.

### 간격, 모서리, 그림자

- 간격은 4pt 그리드입니다: `space-1`(4) `space-2`(8) `space-3`(12) `space-4`(16) `space-6`(24) `space-8`(32) `space-12`(48).
- 화면 좌우 여백은 iPhone `space-4`, iPad `space-6`. 카드 안쪽은 `space-4`.
- 모서리: 배지·작은 버튼 `radius-sm`, 버튼·선택지 `radius-md`, 카드·시트 `radius-lg`, 칩·진도 막대 `radius-pill`.
- 그림자는 둘뿐입니다. 바탕 위 카드는 `shadow-card`, 떠 있는 시트와 고정 바는 `shadow-sheet`. 그 밖의 깊이는 바탕색 차이로 만듭니다.
- 카드에 색 왼쪽 테두리를 두지 않습니다. 과목 표시는 카드 상단의 과목색 띠로 합니다.

### 로고

아직 로고가 없습니다. 앱 이름은 `heading` 스타일의 `ink-primary` 글자로만 표기합니다. 로고를 임의로 그리지 않습니다.

## 아이콘

- iOS 기본 SF Symbols를 권장합니다. 선 굵기는 1.5px(Regular), 크기는 텍스트와 맞춥니다.
- 아직 아이콘 에셋은 없습니다. 미리보기의 아이콘은 같은 규칙으로 그린 임시 인라인 SVG입니다.
- 이름 있는 쓰임: 홈 `house`, 학습 `book`, 모의고사 `doc.text`, 내 기록 `chart.bar`, 정답 `checkmark.circle`, 오답 `xmark.circle`, 시간 `clock`, 읽음 `checkmark`, 다음 `chevron.right`.
- 이모지를 아이콘으로 쓰지 않습니다.

## 접근성

- **Dynamic Type**: 모든 텍스트 스타일은 iOS 텍스트 크기 설정에 따라 커집니다. 고정 높이 대신 최소 높이를 씁니다. 큰 글자에서는 가로 배치를 세로로 바꿉니다.
- **탭 대상**: 최소 44×44pt(`tap-min`). 시각적으로 작은 요소도 터치 영역은 44pt를 확보합니다.
- **VoiceOver**: 아이콘만 있는 버튼에는 라벨을 붙입니다. 선택지는 “선택지 2, 갑상연골, 선택됨”처럼 번호·내용·상태를 읽게 합니다. 채점 후에는 “정답” 또는 “오답”을 먼저 읽습니다. 진도 링은 “진도 64퍼센트”로 읽습니다.
- **대비**: 텍스트 4.5:1, 의미 있는 선·아이콘·그래픽 3:1을 두 테마 모두에서 지킵니다.
- **동작 줄이기**: 「모션」 섹션을 따릅니다.

## 배치: iPhone과 iPad

- **iPhone**: 한 열. 하단 탭 바(`tabbar-height`)와 홈 인디케이터 안전 영역을 둡니다. 과목 카드는 세로로 쌓습니다.
- **iPad 가로**: 왼쪽 과목 사이드바(`sidebar-width`, `surface-sidebar`) + 오른쪽 콘텐츠의 두 열 분할 화면. 탭 바 대신 사이드바가 내비게이션입니다.
- **iPad 세로·홈**: 과목 카드 세 장을 한 줄 그리드로 놓습니다.
- 학습자료 본문은 `content-max`(720px)를 넘기지 않습니다.
- 상단·하단 안전 영역 안에 모든 컨트롤을 둡니다. 시험 바는 상단 안전 영역 바로 아래에 고정합니다.
