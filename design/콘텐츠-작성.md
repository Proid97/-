# 콘텐츠 작성

학습자료, 퀴즈 문항, 해설을 쓸 때의 규칙입니다. 정확하고 짧게, 한 번에 하나씩 씁니다.

## 학습자료

- 한 챕터는 8~12분 분량으로 나눕니다. 읽는 시간을 목록에 표시합니다.
- 소제목은 내용을 요약하는 명사구로 씁니다: “후두의 연골”, “음운 발달 단계”.
- 한 문단은 3~4문장. 핵심 용어는 처음 나올 때 굵게 쓰고 영문을 괄호로 병기합니다: **윤상갑상근**(cricothyroid muscle).
- 그림에는 번호와 설명을 붙입니다: “그림 3-2. 후두의 정면도”. 그림 속 라벨은 본문 용어와 똑같이 씁니다.
- 목록은 순서가 있을 때만 번호를 씁니다(발달 단계, 평가 절차).
- 출처가 있는 수치는 연도와 함께 씁니다.

## 퀴즈 문항

- 문항은 “~은?”, “~으로 옳은 것은?”처럼 질문으로 끝냅니다.
- 하나의 문항은 하나의 개념만 묻습니다.
- 부정형은 꼭 필요할 때만 쓰고 **아닌**, **틀린**을 굵게 표시합니다.
- 선택지는 4개. 길이와 형태(모두 명사, 모두 문장)를 맞춥니다. “모두 옳다”, “정답 없음”은 쓰지 않습니다.
- 오답 선택지는 실제로 헷갈리는 개념에서 고릅니다. 예: 성대를 늘이는 근육을 물을 때 갑상피열근, 후윤상피열근, 외측윤상피열근.

예시:

> 성대를 길게 늘여 음높이를 높이는 근육은?
> ① 갑상피열근 ② 후윤상피열근 ③ 윤상갑상근 ④ 외측윤상피열근

## 해설

- 순서: 결과 → 정답 → 이유 한두 문장 → (필요하면) 오답 선택지가 틀린 이유.
- 정답일 때: “정답이에요. 윤상갑상근은 갑상연골을 앞으로 기울여 성대를 늘입니다.”
- 오답일 때: “오답이에요. 정답은 ③ 윤상갑상근입니다. ① 갑상피열근은 성대를 짧고 두껍게 만듭니다.”
- 해설은 해당 학습자료 챕터로 연결합니다: “3장 후두의 근육에서 다시 보기”.

## 모의고사 결과 문구

- 점수는 사실로만 전합니다: “84점 · 40문항 중 34문항 정답”.
- 비교는 지난 회차와만 합니다: “지난번보다 8점 올랐어요.”
- 약한 주제는 구체적으로 짚습니다: “실어증 분류 정답률이 50%예요. 오답 6문항을 복습해 보세요.”

## 용어 표기

| 쓰는 표기 | 쓰지 않는 표기 |
|---|---|
| 성대 | 성대주름(본문 첫 언급 외) |
| 실어증 | 失語症, aphasia 단독 |
| 음운 변동 | 음운 프로세스 |
| 모의고사 | 모의시험, 테스트 |
| 오답 복습 | 틀린 문제 다시 보기 |
