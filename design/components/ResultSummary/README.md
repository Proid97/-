# ResultSummary

모의고사를 마친 뒤 보여 주는 결과 카드로, 점수 · 정답/오답 수 · 주제별 정답률 · 오답 복습 버튼으로 이루어집니다.

## 사용하는 쪽이 정하는 것
- 과목, 회차, 소요 시간, 점수, 전체·정답 문항 수, 지난 회차와의 차이.
- 주제별 정답률 목록(3~6개), 오답 복습으로 이동하는 동작.

## 상태
- 정답률 60% 미만 주제: 경고 아이콘 + “보충 필요 · 오답 n문항”(`warning-ink`).
- 오답 0개: 버튼을 “전체 문항 다시 보기”(보조)로 바꿉니다.

## 규칙
- 점수는 `score` mono, 단위 “점”은 `heading`. 점수에 색을 넣지 않습니다.
- 정답·오답 수는 `correct-soft`/`incorrect-soft` 칸에 아이콘과 라벨을 함께 씁니다.
- 주제별 막대는 과목색(`subject-*`), 퍼센트는 `ink-secondary` mono.
- 문구는 사실만 전합니다: “지난번보다 8점 올랐어요.” 느낌표와 축하 이모지는 쓰지 않습니다.
- 하지 말 것: 점수에 따라 카드 전체 색 바꾸기, 등수·백분위 같은 근거 없는 수치.
