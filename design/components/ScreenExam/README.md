# ScreenExam

iPhone 모의고사 문항 화면의 구성 예시로, ExamTimer · 문항 · QuizOption 네 개 · 이전/다음 버튼으로 이루어집니다.

## 구성
- 상단 고정 ExamTimer(탭 바는 숨김).
- 문항 번호(`figure` 숫자)와 “나중에 보기” 조용한 버튼.
- 과목 · 주제 캡션, 문항(`subheading`), 선택지 네 개(선택 상태만, 채점 없음).
- 하단 고정 바: “이전”(보조) + “다음”(주). 마지막 문항에서는 “다음” 대신 “제출”.

## 규칙
- 모의고사 중에는 정답을 보여 주지 않습니다. 정답·오답 상태는 오답 복습에서만 씁니다.
- 하단 바는 홈 인디케이터 안전 영역(34pt)을 비웁니다.
- 하지 말 것: 시험 중 탭 바 노출, 선택 즉시 다음 문항으로 자동 이동.
