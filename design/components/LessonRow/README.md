# LessonRow

학습자료 목록의 한 행으로, 챕터 번호 · 제목 · 분량 · 읽음 상태를 보여 줍니다.

## 사용하는 쪽이 정하는 것
- 과목(번호 타일 색), 챕터 번호(두 자리), 제목, 메타(“읽는 시간 10분 · 그림 5”), 읽음 상태.
- 행을 눌렀을 때 열 챕터.

## 상태
- 안 읽음: “안 읽음” `ink-secondary`.
- 읽는 중: “40% 읽는 중” `subject-*-ink` 600.
- 읽음: 체크 아이콘 + “읽음”, 제목은 `ink-secondary`로 한 단계 낮춥니다.
- 눌림: 행 바탕 `surface-sidebar`.

## 규칙
- 행 최소 높이 64pt, 좌우 `space-4`. 행 사이는 `border-subtle` 구분선.
- 번호 타일은 40pt, `subject-*-soft` 바탕에 `subject-*-ink` mono 숫자.
- 상태는 항상 글자로 씁니다. 아이콘만으로 읽음을 표시하지 않습니다.
- VoiceOver: “3장, 후두의 구조: 연골과 관절, 10분, 안 읽음”.
- 하지 말 것: 제목 두 줄 넘김(말줄임 대신 줄바꿈 허용, 최대 2줄), 진도 막대를 행마다 넣기.
