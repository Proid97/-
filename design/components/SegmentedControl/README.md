# SegmentedControl

과목 화면 상단에서 학습자료 · 퀴즈 · 모의고사 세 기능을 오가는 세그먼트 컨트롤입니다.

## 사용하는 쪽이 정하는 것
- 세 칸의 라벨(고정: 학습자료, 퀴즈, 모의고사)과 현재 선택된 칸.
- 선택이 바뀔 때 아래 콘텐츠를 바꾸는 처리.

## 상태
- 선택됨: `surface-elevated` 칸 + `shadow-card`, `ink-primary` 600.
- 선택 안 됨: 투명, `ink-secondary`.
- 포커스: 칸 둘레에 `focus-ring`.

## 규칙
- 외곽은 `surface-sidebar` 바탕과 `border-subtle` 선, 높이 36pt 이상, 터치 영역은 44pt를 맞춥니다.
- 과목색을 칸 바탕에 쓰지 않습니다. 과목 표시는 화면 제목 아래 진도 막대가 맡습니다.
- 마지막으로 연 칸을 과목마다 기억합니다.
- VoiceOver에서는 탭으로 읽히게 합니다: “퀴즈, 탭, 3개 중 2번째, 선택됨”.
- 하지 말 것: 네 칸 이상 늘리기, 아이콘만 넣기.
