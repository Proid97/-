# ProgressRing

과목 진도를 원형으로 보여 주는 표시로, 가운데에 퍼센트를 씁니다.

## 사용하는 쪽이 정하는 것
- 값(0~100), 과목(링 색), 크기(작게 48 · 기본 72 · 크게 112), 접근성 라벨의 과목 이름.

## 상태
- 0%: 트랙만 표시하고 가운데에 “0%”.
- 100%: 링을 모두 채우고 가운데에 체크 아이콘과 “완료”.

## 규칙
- 트랙 `border-subtle`, 값 `subject-*`(그래픽 3:1 이상), 숫자 `subject-*-ink` mono.
- 숫자 크기: 48 → 13px, 72 → 17px, 112 → 28px. 13px 아래로 줄이지 않습니다.
- 처음 나타날 때 400ms 동안 채웁니다. 동작 줄이기에서는 바로 표시합니다.
- VoiceOver: “언어발달 진도 38퍼센트”. SVG 자체는 숨기고 바깥 요소에 라벨을 붙입니다.
- 하지 말 것: 링 안에 퍼센트 외 문장 넣기, 여러 값을 한 링에 겹치기, 그라데이션.
