# ExamTimer

모의고사 화면 상단에 고정되는 시험 바로, 남은 시간 · 문항 번호 · 제출 버튼과 진행 막대를 보여 줍니다.

## 사용하는 쪽이 정하는 것
- 남은 시간(mm:ss), 현재 문항 번호와 전체 문항 수, 제출 버튼 동작.

## 상태
- 기본: 시계 아이콘 + `timer` 숫자(`ink-primary`).
- 경고(5분 미만): `warning-soft` 알약 바탕, `warning-ink` 숫자와 “5분 미만” 라벨. 색만 바뀌고 깜빡이지 않습니다.
- 시간 종료: 자동 제출 후 결과 화면으로 이동합니다.

## 규칙
- 바탕 `surface-elevated` + `shadow-sheet`, 상단 안전 영역 바로 아래 고정, 높이 56pt.
- 숫자는 모두 mono(`timer`, `figure`)로 자릿수가 흔들리지 않게 합니다.
- 진행 막대는 `accent` 3px. 과목색을 쓰지 않습니다.
- “제출”은 바로 제출하지 않고 제출 확인 시트를 엽니다.
- VoiceOver: 1분마다 읽지 않습니다. 5분, 1분 남았을 때만 알립니다.
- 하지 말 것: 초 단위 깜빡임, 빨간색 전체 배경, 경고에 소리만 쓰기.
