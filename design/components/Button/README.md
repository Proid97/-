# Button

화면에서 할 일을 실행하는 버튼으로, 주(primary)·보조(secondary)·조용한(quiet) 세 종류가 있습니다.

## 사용하는 쪽이 정하는 것
- 라벨: 동사로 끝나는 2~6자. “시작하기”, “제출”, “오답 복습”.
- 종류(`primary` · `secondary` · `quiet`)와 크기(큰 50 · 기본 44 · 작은 32).
- 선택 사항: 앞이나 뒤에 붙일 아이콘 하나, 비활성 여부, 전체 폭 여부.

## 상태
- 기본, 눌림(배경 8% 어둡게, 150ms), 비활성(`border-subtle` 바탕 + `ink-tertiary` 글자), 키보드 포커스(`focus-ring` 2px, 간격 2px).

## 규칙
- 주 버튼(`accent` 바탕, `on-accent` 글자)은 한 화면에 하나만 둡니다. 화면의 목적이 되는 행동에만 씁니다.
- 보조 버튼은 `surface-card` 바탕, `border-strong` 테두리, `accent-ink` 글자입니다.
- 조용한 버튼은 “해설 보기”, “나중에 보기”처럼 가벼운 행동에 씁니다.
- 작은 버튼도 터치 영역은 44pt(`tap-min`)를 확보합니다.
- 하지 말 것: 주 버튼 두 개 나란히 두기, 라벨 끝에 마침표, 흰색 글자를 직접 지정하기(다크에서 `on-accent`는 어두운 색입니다).
