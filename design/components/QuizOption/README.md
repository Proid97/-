# QuizOption

객관식 문항의 선택지로, 기본 · 선택 · 정답 · 오답 네 상태를 가집니다.

## 사용하는 쪽이 정하는 것
- 번호(1~4), 선택지 문장, 상태.
- 채점 시점: 퀴즈는 선택 즉시, 모의고사는 제출 후 오답 복습에서만 정답·오답을 보여 줍니다.

## 상태
- 기본: `surface-card` 바탕, `border-strong` 1px.
- 선택: `accent-soft` 바탕, `accent` 2px, 번호 원 채움(`on-accent` 숫자).
- 정답: `correct-soft` 바탕, `correct` 2px, 체크 아이콘 + “정답” 라벨(`correct-ink`).
- 오답: `incorrect-soft` 바탕, `incorrect` 2px, X 아이콘 + “오답” 라벨(`incorrect-ink`).
- 채점 후 나머지 선택지는 `ink-secondary`로 낮춥니다.

## 규칙
- 정답·오답은 색, 아이콘, 라벨 세 가지를 늘 함께 씁니다. 색만으로 알리지 않습니다.
- 최소 높이 56pt, 선택지 사이 `space-3`. 문장은 줄바꿈을 허용합니다.
- 전환은 150~250ms. 오답에 흔들기 효과를 쓰지 않습니다.
- VoiceOver: “선택지 2, 윤상연골, 선택됨” → 채점 후 “정답, 선택지 2, 윤상연골”.
- 하지 말 것: 라디오 버튼 모양의 작은 원만 누르게 하기(행 전체가 탭 대상), 빨강·초록 바탕만으로 결과 표시.
