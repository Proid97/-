# 모션

움직임은 상태가 바뀌었다는 사실을 알려 줄 때만 씁니다. 장식용 애니메이션은 없습니다.

## 지속 시간

| 이름 | 시간 | 쓰임 |
|---|---|---|
| 짧게 | 150ms | 선택지 선택, 버튼 눌림, 세그먼트 전환, 체크 표시 |
| 보통 | 250ms | 채점 결과 표시, 탭 전환, 목록 펼침 |
| 길게 | 400ms | 시트 열고 닫기, 화면 푸시, 진도 링 채움 |

400ms를 넘는 움직임은 만들지 않습니다.

## 가속

- 들어오는 요소: `cubic-bezier(0.2, 0, 0, 1)` (빠르게 시작해 부드럽게 멈춤).
- 나가는 요소: `cubic-bezier(0.4, 0, 1, 1)`, 들어올 때보다 짧게.
- 시트와 화면 전환은 iOS 기본 스프링을 그대로 씁니다.

## 퀴즈 피드백

- 채점은 선택 직후 150ms 안에 시작합니다. 선택지 테두리와 바탕이 250ms 동안 `correct-soft` 또는 `incorrect-soft`로 바뀌고 아이콘이 나타납니다.
- 오답일 때 흔들기 효과를 쓰지 않습니다. 틀린 것을 벌주는 느낌을 주지 않습니다.
- 정답 시 짧은 햅틱(success), 오답 시 햅틱(warning)을 씁니다. 소리는 기본으로 끕니다.

## 진도와 타이머

- 진도 링과 막대는 화면에 들어올 때 0에서 현재 값까지 400ms 동안 채웁니다. 같은 세션에서 다시 볼 때는 바로 표시합니다.
- 타이머 숫자는 깜빡이지 않습니다. 5분 미만이 되면 색만 250ms 동안 `warning-ink`로 바뀝니다.

## 동작 줄이기

- iOS “동작 줄이기”가 켜져 있으면 이동·확대 애니메이션을 모두 크로스페이드(150ms)로 바꿉니다.
- 진도 링은 채우는 동작 없이 최종 값을 바로 보여 줍니다.
- 웹 미리보기에서는 `@media (prefers-reduced-motion: reduce)`로 같은 규칙을 적용합니다.
