# 프로젝트 컨텍스트 (입구 노트)

언어치료학 대학원생을 위한 학습 앱. 아이패드·아이폰 대상.

## 구조
- 과목 3개: 언어기관해부생리, 언어발달, 의사소통장애개론
- 과목마다 기능 3개: 학습자료, 퀴즈, 모의고사
