# 실수와 교훈

새 작업을 시작하기 전에 이 문서를 먼저 읽는다.

## 2026-10-10 디자인 시스템 생성
- 무엇이 잘못됐나 → 에이전트가 색인 파일(design-system.json)을 엉뚱한 위치에 두고, 페이지가 자동 생성하는 tokens.css까지 직접 만들었다.
- 왜 그랬나 → 지시문에 "참고 문서를 읽어라"고만 했더니, 참고 문서와 내 지시가 어긋난 부분을 에이전트가 스스로 해석했다.
- 다음에 어떻게 하나 → 파일 경로와 "만들지 말 파일"을 지시문에 명시하고, 참고 문서보다 내 지시가 우선임을 밝힌다.

- 무엇이 잘못됐나 → 사용자 설정에 노트 경로가 doc/Obsidian과 Docs/Obsidian 두 가지로 적혀 있어 하나를 골라야 했다.
- 왜 그랬나 → 설정 문구가 서로 달랐다.
- 다음에 어떻게 하나 → Docs/Obsidian 하나로 통일했다. 다른 경로를 원하면 사용자에게 확인한다.

## 2026-10-10 참고 디자인 조사
- 무엇이 잘못됐나 → 1차 디자인이 AI스럽게 나왔다.
- 왜 그랬나 → 에이전트에 토큰 수치와 컴포넌트 목록만 주고, 참고 화면이나 "하지 말 것"을 구체적으로 주지 않았다.
- 다음에 어떻게 하나 → 디자인 작업은 참고 앱 이름, 따라 할 패턴, 피할 패턴을 지시문에 먼저 적는다.

- 무엇이 잘못됐나 → 화면을 직접 보고 평가하겠다고 했지만 네트워크가 막혀 못 했다.
- 왜 그랬나 → 외부 접속 가능 여부를 확인하기 전에 방법을 약속했다.
- 다음에 어떻게 하나 → 외부 자료가 필요한 작업은 먼저 접속을 확인하고, 막히면 바로 사용자에게 설정 변경을 요청한다.
