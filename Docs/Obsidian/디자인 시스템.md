# 디자인 시스템

아티팩트: https://claude.ai/artifact/UoyV1WVZUYAs5U5hjsseWq
원본 파일: `design/` (tokens.json, README.md, components/*)

## 방향
- 분위기: 차분한 학술·임상 느낌. 따뜻한 미색 바탕, 짙은 먹색 글자, 남색 포인트 하나.
- 과목별 색 (밝기까지 다르게): 해부생리=짙은 청록, 언어발달=호박색, 장애개론=자두색
- 정답/오답/경고 색은 아이콘과 글자 라벨을 항상 함께 쓴다 (색만으로 구분하지 않음).
- 라이트·다크 두 테마. 글자 대비 4.5:1 이상 검증 완료.

## 글꼴
- 본문: IBM Plex Sans KR (Google Fonts), 숫자·타이머: IBM Plex Mono
- 크기 7단계: display 34 / title 28 / heading 22 / subheading 17 / body 17 / callout 15 / caption 13

## 간격·모서리
- 4pt 격자: 4, 8, 12, 16, 24, 32, 48
- 모서리: 8, 12, 20, pill(999)
- 탭 최소 44pt

## 컴포넌트 (12개 + 커버)
Button, SegmentedControl, TabBar, SubjectCard, LessonRow, QuizOption, ProgressRing, ExamTimer, ResultSummary, ScreenHome, ScreenExam, ScreenIPad

## 화면 흐름
홈 → 과목 → 세그먼트 3탭(학습자료/퀴즈/모의고사)
모의고사: 시작 → 문항 → 제출 확인 → 결과 → 오답 복습
아이패드: 왼쪽 과목 사이드바 + 오른쪽 내용 (2단)

## 남은 일
- 로고·아이콘 없음 (글자 워드마크로 대체). SF Symbols 권장.
- 정답/오답 색은 밝기 차이가 거의 없음. 색각 이상 대응을 더 강하게 하려면 정답 색을 파란 쪽으로 옮기는 안 검토.
